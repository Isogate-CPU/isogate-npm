# Code of Conduct

## Our standard

We expect everyone participating in this project to be respectful, curious,
and constructive. Harassment, discrimination, personal attacks, intimidation,
and unwanted sexual attention are not acceptable.

## Responsibilities

Maintainers may remove comments, reject contributions, or restrict
participation when behavior violates this standard. They will aim to apply
these rules fairly and consistently.

## Reporting

Report conduct concerns privately to
[support@isogate.tech](mailto:support@isogate.tech). Please include enough
context to investigate and avoid sharing unrelated private information.

## Scope

This code of conduct applies to project spaces and to public interactions
where an individual is representing the project.
