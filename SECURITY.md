# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[support@isogate.tech](mailto:support@isogate.tech). Include the affected
package and version, a clear description, reproduction steps or a minimal
proof of concept, and any suggested mitigation. Please do not open a public
issue for an unpatched vulnerability.

We will acknowledge a report when practical, investigate it, and coordinate a
public fix or advisory after a mitigation is available. Do not include
credentials, private host data, or other sensitive information in reports.

## Scope

This policy covers the source and published artifacts for `@isogate/node` and
`@isogate/replay` in this repository. The packages are not a sandbox: do not
pass untrusted input to a process or network integration without applying
your own operational controls.
